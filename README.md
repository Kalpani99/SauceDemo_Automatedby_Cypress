# SauceDemo_Automatedby_Cypress
⏩ This project demonstrates end-to-end test automation of the SauceDemo web application using Cypress.💻
📋 Features automated:
🔹 User login authentication 
🔹Product selection & add to cart 
🔹 Checkout process validation 
🔹Logout functionality
The project follows a structured test approach with reusable commands and assertions to ensure application reliability.
